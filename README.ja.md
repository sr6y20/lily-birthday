# お誕生日おめでとう 🎂 · Birthday Wish

動く和風のバースデーカード。折り紙の星がページを渡ってバースデーレターを届け、読み終わったら記念カードに折って画像保存ができます。日中英の3言語対応、完全フロントエンド、バックエンド不要。

[中文 README](./README.md) · [English README](./README.en.md)

## 特徴

- **カードの構成**：鳥居と和紙の質感のオープニング、ロウソクを吹き消せるバースデーケーキ、俳句、祝福の手紙、タイムライン
- **めくる祝福カード**：3つの願い（健康平安／夢実現／素敵な出会い）。クリックまたはキーボードの Enter / Space でめくれます（GSAP Flip）
- **折り紙の星の旅**：自然なスクロールに連動して、星が祝福セクションからフッターの封筒まで移動します（`Flip.fit` + `ScrollTrigger`）。レイアウト変更時には自動で再構築
- **バースデーレター**：封筒をクリックして開封。封・用紙・本文がタイムライン順に現れ、文末には選んだ願いに応じた図案（桜の枝／星の軌跡／結び目）が DrawSVG で描かれます
- **記念カード**：「もう一度読む」で再び開封でき、「手紙をしまむ」で用紙を記念カードに折りたたみます。画像保存ボタンで Canvas API により 1080×1440 の PNG として保存可能（すべてローカルで生成、アップロードなし）
- **3言語切替**：日本語／中文／English。選択は localStorage に保存され、`html lang` と文書タイトルも追従
- **環境エフェクト**：花火、桜、流れる星、ホタル、マウストレイル、紙吹雪、折鶴と提灯。いずれも `prefers-reduced-motion` 対応

## はじめ方

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ へ本番ビルド
npm run preview  # ビルド成果物をプレビュー
```

## URL パラメーター

| パラメーター | 内容                                 | 例                               |
| ------------ | ------------------------------------ | -------------------------------- |
| `date`       | 誕生日。`M-D` または `YYYY-M-D` 形式 | `?date=11-12`、`?date=2027-2-21` |

- 未指定・不正な値（`2-30`、`abc`）はデフォルトの **2月26日** にフォールバック
- 指定した日付はページ上部・レター・記念カード・PNG 出力に反映され、言語ごとの表記（令和年号＋`二月二十一日`／`February 21st`）で表示されます

## プロジェクト構成

```
src/
├── App.vue            # ページ構成、GSAP アニメーション、DrawSVG 図案、PNG 出力
├── App.css            # 全スタイルとテーマ変数（--wish-accent / --wish-ink が願いに応じて切替）
├── i18n.js            # vue-i18n 設定と言語の永続化
├── locales/           # zh / en / ja のコピー
└── components/        # ケーキ・折鶴・提灯・花火などの独立エフェクト
```

## カスタマイズ

- **願いと本文**：`src/locales/*.json` の `wishes.items` と `letter.*` を編集
- **署名**：`message.signature` を編集
- **図案のパス**：`App.vue` の `motifVariants` がレター描画・記念カード・PNG の単一の情報源です。1か所の修正で3か所に反映
- **配色**：`App.css` 冒頭の `.app[data-wish="N"]` 変数ブロック

## 補足

- 画像保存はブラウザ内で完結し、内容を収集・アップロードすることはありません
